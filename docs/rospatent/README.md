# Материалы для регистрации программы в Роспатенте

Оформлены по приказу Минэкономразвития России от 05.04.2016 № 211.

| Файл | Что это | Пункт приказа |
|---|---|---|
| `referat.pdf`, `referat.docx` | Реферат, 817 знаков (норма — не больше 900) | п. 30 |
| `deposit.pdf` | Депонируемые материалы: титульный лист и 60 страниц исходного текста в формате PDF/A-2b | пп. 26–29 |

Оформление: А4, поля 20/20/20 мм и левое 25 мм, чёрный шрифт 12 пт, интервал 1,5 (п. 14).
Оба PDF прошли проверку veraPDF на соответствие PDF/A-2b.

## Что вписать перед подачей

Откройте `data.json` и заполните:

- `holder` — правообладатель, полное наименование, например «ООО "ПВ-Система"»;
- `authors` — авторы: `[{"name": "Иванов Иван Иванович"}]`;
- `city` — город на титульном листе.

Затем пересоберите файлы:

```
pip install --target=/tmp/pylibs fpdf2 pikepdf python-docx
PYTHONPATH=/tmp/pylibs python3 docs/rospatent/build.py
```

## Что в депонируемых материалах

- Свой исходный код программы: C# (Windows), Python (сервер), TypeScript (интерфейс).
- Чужие библиотеки не включены.
- Взяты первые 30 и последние 30 страниц полного текста (1049 страниц).
  Внизу каждой страницы — сквозной номер и номер в полном тексте в скобках.
- Адреса серверных функций и ключ проверки лицензий заменены на `***`.

Объём исходного текста: 1 295 131 байт (1,24 Мб).
