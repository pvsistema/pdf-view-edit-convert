# ПВ-Система PDF — сборка десктопной версии

Программа собирается в один файл `PVSPDF.exe` и ставится в папку **C:\PVSPDF**.

## Что нужно на компьютере сборки

| Программа | Где взять | Когда нужна |
|---|---|---|
| Node.js LTS | https://nodejs.org | всегда |
| .NET 8 SDK (именно SDK, не Runtime) | https://dotnet.microsoft.com/download/dotnet/8.0 | всегда |
| Inno Setup 6 | https://jrsoftware.org/isdl.php | только для установщика |

На компьютере пользователя **ничего ставить не нужно** — установщик сам
доустановит компонент просмотра (WebView2), если его нет.

## Установщик для пользователей (рекомендуется)

```
desktop\csharp\build.bat installer
```

Получится **один файл** в `desktop\csharp\installer-out`:

```
PVSPDF-Setup-1.0.0.exe
```

Его и передавайте пользователям. Пользователь просто запускает файл — программа
ставится в `C:\PVSPDF`, появляются ярлыки на рабочем столе и в «Пуске»,
в «Установке и удалении программ» появляется запись для удаления.
При установке можно отметить галочку «Открывать файлы PDF этой программой».

## Как собрать

Скопируйте **весь проект** на компьютер с Windows и запустите:

```
desktop\csharp\build.bat
```

Готовые файлы появятся в `desktop\csharp\dist`:

```
PVSPDF.exe          сама программа
web\                файлы интерфейса
app_version.txt     номер версии
pvspdf.ico          значок
```

## Как сразу установить в C:\PVSPDF

Запустите от имени администратора:

```
desktop\csharp\build.bat install
```

Скрипт соберёт программу, скопирует всё в `C:\PVSPDF`
и создаст ярлыки на рабочем столе и в меню «Пуск».

## Другие режимы

| Команда | Что делает |
|---|---|
| `build.bat` | обычная сборка с защитой кода |
| `build.bat installer` | сборка + один файл PVSPDF-Setup.exe для пользователей |
| `build.bat install` | сборка + установка на этот компьютер в C:\PVSPDF |
| `build.bat noobf` | сборка без защиты — для поиска причины ошибки |
| `uninstall.bat` | удаление программы из C:\PVSPDF |

Команды можно совмещать: `build.bat installer noobf`.

## Номер версии

Версия задаётся вручную в файле `desktop\APP_VERSION` — одна строка вида `1.0.0`.
Перед выпуском новой версии впишите туда новый номер (он должен быть больше прежнего).
Номер попадает и в имя установщика, и в свойства программы.

## Обновление у пользователя

Программа обновляется сама. Раз в сутки она спрашивает сервер о новой версии
и, если та вышла, показывает окно с описанием изменений.

По кнопке «Обновить» всё происходит без участия пользователя:

1. Установщик скачивается прямо в программе, с полосой загрузки и объёмом в МБ.
   Загрузку можно отменить.
2. Программа закрывается, помощник установки останавливает её службы
   (`PVSPDFService`, `PVSPDFPrint`, если заведены) и снимает оставшиеся процессы.
3. Новая версия ставится тихо, без окон мастера (`/VERYSILENT`).
4. Программа запускается заново, службы поднимаются обратно.

Ярлыки, связь с файлами PDF и настройки при этом сохраняются.

Ручной путь тоже работает: запустить `PVSPDF-Setup-X.Y.Z.exe` поверх старой версии.

Чтобы выпустить обновление: поднять номер в `desktop\APP_VERSION`, собрать
`build.bat installer`, выложить полученный файл и указать ссылку на него
в панели администратора (раздел версий).

## Если сборка прервалась

Полный журнал: `desktop\csharp\build.log`.
Скрипт сам проверяет наличие Node.js и .NET 8 SDK и пишет, чего не хватает.
