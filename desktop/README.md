# ПВ-Система PDF — сборка десктопной версии

Программа собирается в один файл `PVSPDF.exe` и ставится в папку **C:\PVSPDF**.

## Что нужно на компьютере сборки

| Программа | Где взять |
|---|---|
| Node.js LTS | https://nodejs.org |
| .NET 8 SDK (именно SDK, не Runtime) | https://dotnet.microsoft.com/download/dotnet/8.0 |

На компьютере пользователя нужен только **Microsoft Edge WebView2 Runtime** —
в Windows 10 и 11 он уже установлен. Если нет:
https://developer.microsoft.com/microsoft-edge/webview2/

## Как собрать

Скопируйте **весь проект** на компьютер с Windows и запустите:

```
desktop\csharp\build.bat
```

Готовые файлы появятся в `desktop\csharp\dist`:

```
PVSPDF.exe          сама программа
web\                файлы интерфейса
app_version.txt     номер версии
pvspdf.ico          значок
```

## Как сразу установить в C:\PVSPDF

Запустите от имени администратора:

```
desktop\csharp\build.bat install
```

Скрипт соберёт программу, скопирует всё в `C:\PVSPDF`
и создаст ярлыки на рабочем столе и в меню «Пуск».

## Другие режимы

| Команда | Что делает |
|---|---|
| `build.bat` | обычная сборка с защитой кода |
| `build.bat noobf` | сборка без защиты — для поиска причины ошибки |
| `build.bat install` | сборка + установка в C:\PVSPDF |
| `uninstall.bat` | удаление программы из C:\PVSPDF |

## Номер версии

Версия задаётся вручную в файле `desktop\APP_VERSION` — одна строка вида `1.0.0`.
Перед выпуском новой версии впишите туда новый номер (он должен быть больше прежнего).

## Если сборка прервалась

Полный журнал: `desktop\csharp\build.log`.
Скрипт сам проверяет наличие Node.js и .NET 8 SDK и пишет, чего не хватает.
